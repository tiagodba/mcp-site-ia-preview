TX x RX — entenda sem confusão

TX — Transmit

É a potência óptica que o equipamento local transmite para o enlace.

Se um SFP transmite aproximadamente -3 dBm, esse é o TX daquele lado.

RX — Receive

É a potência óptica que o equipamento local recebe do lado remoto.

Se o equipamento lê -18 dBm, esse é o RX recebido naquela interface.
Importante: não existe um único valor de RX “bom” para todos os módulos. Compare o RX medido com a Receiver Sensitivity e o Receiver Overload do transceiver usado.
dBm menos negativo = sinal mais forte. Ex.: -5 dBm é mais forte que -20 dBm.
Abaixo da sensibilidade: sinal fraco demais; pode haver perda, erros ou link DOWN.
Acima do overload: sinal forte demais; o receptor pode saturar.
Dentro da janela: ainda avalie margem, estabilidade, erros, CRC/FCS e documentação do módulo.

Roteiro rápido de diagnóstico óptico

1. Confirme se a interface está administrativamente UP.
2. Leia TX e RX no transceiver/DOM/DDM.
3. Compare RX com sensibilidade e overload do módulo.
4. Verifique CRC/FCS, drops, flaps e alarmes.
5. Confira conectores, limpeza, patch cord, emendas, splitter e curvaturas.
6. Compare o mesmo enlace pelo lado remoto.
7. Documente TX, RX, modelo do SFP, distância e horário.

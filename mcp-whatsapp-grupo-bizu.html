PERGUNTA DA ENQUETE
🔧 Primeira utilização no computador
Instale uma extensão de userscripts, como Tampermonkey, e depois abra o arquivo MCP Enquete Helper. O helper adiciona o botão flutuante “MCP ENQUETE” dentro do WhatsApp Web. Esta automação não é uma API oficial do WhatsApp e pode precisar de ajustes se a interface mudar.
💡 Depois de clicar em PREPARAR ENQUETE AUTOMÁTICA, os dados ficam na área de transferência. No grupo aberto no WhatsApp Web, clique em MCP ENQUETE. O helper tentará abrir “Enquete” e preencher pergunta e opções. Revise antes de enviar.
